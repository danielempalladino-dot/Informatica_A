COMPUTER SCIENCE A (INFORMATICA A) - COURSEWORK & EXERCISES

====================================================================



Welcome to my repository for "Informatica A" (Computer Science A)

course, completed during my 1st year of Mathematical Engineering

at Politecnico di Milano.



This repository serves as a comprehensive collection of the exercises,

projects, and exam preparation materials developed throughout the course.


--------------------------------------------------------------------

1. REPOSITORY STRUCTURE

--------------------------------------------------------------------



To keep the repository organized, the files are structured into

the following directories:



* Exam/             - Solutions and practice exercises for past

                      exam papers (Prove d'Esame).

* Lab/              - Guided lab assignments and practical

                      exercises (Laboratori).

* Practice_session/ - Classroom practice problems and tutorials

                      (Esercitazioni).

* Ex/ and Extra_Ex  - Custom exercises and challenge problems

                      created to test and consolidate my knowledge.

Lesson/		    - Code i did during the lessons to understand them better




--------------------------------------------------------------------

2. TOPICS COVERED

--------------------------------------------------------------------



The repository covers a wide spectrum of fundamental C programming

and computer science concepts, including:



* C Fundamentals & Memory Model:

  - Variables, Data Types, and Operators

  - Pointers, Memory Layout, and Dynamic Memory Allocation (malloc, free)



* Control Flow & Functions:

  - Conditional statements, loops, and modular programming



* Data Structures:

  - Arrays, Matrices, Strings, and struct definitions

  - Linked Lists (Singly and Doubly Linked Lists)

  - Binary Trees and Binary Search Trees (BSTs)



* Algorithms & Advanced Concepts:

  - Recursion and recursive problem solving

  - File I/O operations (Text and Binary files)

  - Basic sorting and searching algorithms
